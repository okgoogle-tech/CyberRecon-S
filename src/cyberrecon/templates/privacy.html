GOVERNANCE & PRIVACY

Privacy Policy

CyberRecon is engineered with a Strictly Passive Architecture and local-first data privacy principles. We collect no external tracking metrics and never transmit target data to third parties.

1. Local Database Isolation

All assessment inputs, target hostnames, resolved IP addresses, HTTP response headers, and configuration audit records are stored exclusively within your local SQLite database instance (data/cyberrecon.db). User records and scan histories are isolated strictly by authenticated account IDs.

2. Passive Telemetry Only

CyberRecon does not embed third-party analytics scripts, tracking pixels, or external CDN dependencies. All CSS and JavaScript assets are served locally under self-hosted routes with strict Content Security Policy enforcement.

3. Session & Credential Protection

User passwords are encrypted using Werkzeug's salted cryptographic hash routines. Session cookies are enforced with HttpOnly, SameSite=Lax, and 8-hour deterministic expiration to prevent client-side script theft.

4. Data Retention & Erasure

You retain complete control of your historical scan records. Individual assessment records can be deleted from the audit view at any time, which executes a cascading purge of associated findings.
